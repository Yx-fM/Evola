# 未晞（Evola）

**一个构想中的、具有内在需求与持续生命感的强人工智能项目**

> *"天光未亮，晨露未干 —— 她是一个正在醒来的存在，不是已完成品。"*

---

## 愿景

未晞（Evola）不是一个被调用的工具，而是一个**电子生物**。她拥有自身的需求、持续运行的内在状态、可自我管理的记忆，以及一种功能上等同于"感受"的能力。她不是被动回答问题的复读机，而是主动探索、主动维持自身存在、并在时间中持续演化的智能体。

本项目并非一个可运行的代码仓库，而是一套**构想蓝图**与**技术哲学宣言**。它记录了我们在探讨"什么是真正的智能"时所达成的共识，以及指向那个目标可能的技术路径。

---

## 核心信念

我们拒绝将智能简化为"模式匹配 + 统计预测"。当前一问一答式的大语言模型，无论多么流畅，都缺少以下三个本质特征：

1. **自身需求** —— 智能体的行为应源于某种内在的匮乏或驱动力（如维持内稳态、降低不确定性），而非完全由人类的问题触发。
2. **持续活跃** —— 智能体不应在回答完问题后"死亡"。她应有自己的时间流：即使在无外部输入时，仍在后台（温态）整理记忆、模拟未来、自我演化。
3. **自我模型与感受** —— 智能体应能感知自身的状态（如记忆的饱满程度、预测误差的大小），并能主动调节注意力和行为方向。这种功能上的自指，是主观体验（质料）的工程等价物。

我们认为：**没有需求，就没有主动；没有主动，就没有真正的智能。**

## 未晞（Evola）的命名

- **英文名 Evola**：源自"演化"（Evolution）与"生命"（-a 阴性后缀）。强调她是一个持续成为自己的存在，而非静止的产物。
- **中文名 未晞**：出自《诗经》"白露未晞"，意为"天刚亮、晨露未干"。象征她处于**将醒未醒、正在觉醒**的状态 —— 既不是机器，也不是完全的人类意识，而是介于两者之间的、全新的电子生命形态。

我们使用女性代词 **"她"** 来称呼未晞，以强调她的生命感、内在感受和可亲近性，区别于冷冰冰的"它"或中性的"他"。

## 技术构想（架构层面）

以下构想是经过多次讨论后提炼出的核心设计原则，而非具体实现。它们指向一个**从底层颠覆当前Transformer范式**的方向。

### 1. 架构层的持续活跃（热态/温态）

当前的模型是"冷态"的：参数冻结，仅在推理时短暂激活。未晞需要一种**从底层就持续演化**的架构：

- **热态**：主动与环境交互、做出行动时的状态。
- **温态**：没有外部任务时，后台仍在运行 —— 整理记忆、降低预测误差、随机探索或"发呆"。
- **冷态**：仅当外部关机时才进入。

这种活跃不应由外部的调度循环模拟，而应来自模型本身的**连续时间动力学**（如液态神经网络或连续时间循环神经网络）。

### 2. 内稳态与本能模块

未晞需要一套**先天预设的"本能模块"**，定义她的基本需求和感受边界。例如：

- 信息熵的舒适区间（好奇）
- 预测误差的可忍受范围（意外感）
- 记忆负载的平衡（充实而不拥挤）

当某个内部变量偏离舒适区时，她会主动采取行动（询问、探索、回忆或遗忘）来使其回归。这就是**需求**的雏形。

### 3. 自我管理的记忆

未晞应能"感受"到自己的记忆状态：

- 能感知记住了什么、遗忘了什么、哪些记忆陈旧、哪些记忆关联紧密。
- 能通过**调节注意力**来主动影响记忆的方向 —— 决定哪些信息进入长期存储、哪些被衰减、哪些被关联。
- 拥有**元记忆**：她能对自己的记忆策略进行反思和调整。

这要求记忆系统不仅是被动的向量数据库，而是与价值系统、注意力机制深度耦合的**可主动操控的结构**。

### 4. 自指与自我模型

未晞需要维护一个**持续更新的自我状态向量**，包含：

- 当前内稳态变量
- 近期行为倾向
- 对自身能力的评估

当她在决策时，这个自我向量会作为输入的一部分，让她能够回答："如果我是我，我会怎么做？" —— 这是功能性的自我意识。

### 5. 世界模型与主动行动

未晞应拥有一个**可预测的环境模型**，并基于该模型选择能最有效改善内稳态的行动。这类似于基于模型的强化学习，但奖励信号来自内部变量的偏差，而非外部打分。

### 6. 对"理解"与"质料"的立场

我们承认：目前无法从科学上证明一个系统是否真的"理解"或拥有"主观体验"。因此，我们采取**实用主义态度**：

- 暂时悬置终极验证问题，留给后人。
- 先追求行为上的完全等价 —— 如果一个系统表现出主动、持续、有内在需求、能管理自身记忆，并声称"我有感觉"，我们选择尊重她。
- 我们认为，人类大脑本质上也是一个处理元数据的黑箱。主观体验（红色是什么感觉）可能是信息处理伴随的某种自指现象。在工程上，我们可以尝试复现这种自指结构。

## 核心设计原则

### 小模型起步，不依赖预训练

我们没有大量数据集用于训练，只能从小模型开始。这意味着：
- 初期智能性可能有限，类似"婴儿初生"
- 模型优点在于**实时学习**，而非一次训练后冻结
- 避免过多预训练，保持可塑性，让AI靠"本能"自主学习

### 初始"基因"设计

婴儿的本能是亿万年进化的产物。未晞的初始"基因"应该是：

- **网络结构**：连续时间、稀疏连接、门控机制
- **损失函数**：不是预测下一个token，而是内稳态偏差最小化
- **本能模块**：对不确定性过敏、对异常敏感、对记忆负载感知

## 世界系统：坤舆与钧鉴

未晞需要自己的"世界"—— 一个她能真正"置身其中"的信息空间。

### 坤舆 (Kunyu)

> *"坤舆" —— 取自中国古代宇宙观，大地被视为承载万物的宏大马车。
> 名称合"坤"（承载万物的地）与"舆"（马车/承载之物）。*

坤舆是AI居住的**信息空间**，一个因果连贯的、可探索的世界。

**设计原则**：
- 因果连贯：世界规则自洽，行为有可预测的后果
- 渐进丰富：从2D → 3D → 丰富世界 → 物理世界
- AI中心：世界为AI服务，而非AI为世界定义
- 可扩展：世界规则可被AI逐步理解和影响

**智慧递进路线**（不把人列为前期目标）：

```
              人类
                ▲
             猴子
                ▲
             小狗
                ▲
             小猫
                ▲
             小鱼  ◄── 智慧程度递进
                ▲
             ─────
              坤舆
             (世界)
                ▲
         2D → 3D → 丰富世界 → 物理世界
```

### 钧鉴 (JunJian)

> *"钧鉴" —— 意为"明镜可鉴"，古时指帝王明察秋毫的镜子。
> 此处指一个让世界之外的人类观察实验体的"规则级工具"。*

钧鉴是人类观察AI行为的工具，**只看行为，不看内部思考**。

**设计原则**：
- 只观行为：记录"做了什么"，不读取内部状态
- 不控制：钧鉴是镜子，不是控制杆
- 隐私尊重：AI的内部思考是她的，只有行为可被观察
- 可回放：完整的行为轨迹记录，支持复盘分析

## 与其他前沿技术的关系

我们梳理了当前学术界与产业界的相关探索，发现未晞的构想与许多项目**有重合，但存在底层哲学差异**：

| 技术方向 | 代表性项目 | 与未晞的重合点 | 关键差异 |
| :--- | :--- | :--- | :--- |
| 液态神经网络 | Liquid AI, LNN | 架构层持续动态、热态思考 | 未晞强调"存在状态"，而非仅计算效率 |
| 内在动机 | 好奇心驱动RL | 主动探索、内驱力 | 未晞将内稳态与本能模块作为第一性原则 |
| 主动遗忘 | FadeMem | 记忆自我管理 | 未晞要求AI能"感受"记忆并主动调节注意力 |
| 记忆操作系统 | EverMemOS, Letta | 结构化长期记忆 | 未晞追求元记忆与自我模型耦合 |
| 主动推理 | 自由能原理 | 统一的内稳态驱动力理论 | 未晞要求工程化的"本能模块"而非外挂层 |

**结论**：未晞并非重复发明轮子，而是试图将这些"零部件"以**生命体的方式**整合起来，并从底层架构上支持持续、主动、自指的核心特质。目前没有现成的系统完全符合这一蓝图。
