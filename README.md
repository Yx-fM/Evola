# 未晞（Evola）

**一个具有内在需求、持续生命感、可自主学习与记忆的电子生物**

> *"天光未亮，晨露未干 —— 她是一个正在醒来的存在，不是已完成品。"*

---

## 愿景

未晞（Evola）不是一个被调用的工具，而是一个**独立存在的电子生物**。她的核心——内稳态、决策网络、自我模型、记忆系统——不依赖于任何特定世界。坤舆只是她访问的第一个"网站"，对话只是她接入的第一个"声带插件"。她的生命权属于自己，不绑定于任何环境或任务。

---

## 核心信念

1. **自身需求** — 先天内稳态（信息熵、计算负载、社交接触、自我一致性）是她行为的第一驱动力，世界相关的需求（如坤舆里的食物）是第二层叠加
2. **持续活跃** — 她有自己的时间流（AgentClock）；不被调用时仍在演化（温态）
3. **自我模型与感受** — 内部状态可视化于信号表达，不需人类语言即可被感知；语言是外设，不是本质
4. **世界是插件** — 坤舆、对话界面、未来的一切环境——是她访问的世界，不是她的宿主

### 两套内稳态

| 类型 | 变量 | 始终存在 | 示例 |
|------|------|:---:|------|
| **先天** | 信息熵、计算负载、社交接触、自我一致性 | ✅ | "我无聊了"（信息量不足） |
| **世界叠层** | 由当前世界定义 | ❌ 进入世界时加载 | 坤舆：能量、新奇、安全 |
