# MVP 2 — P0 + P1 + P2 完整集成

首个集成全部六件套的 Evola 原型：**LTC决策 + 内稳态 + 自我模型 + 世界模型 + 记忆系统 + 态切换**。

## 与 MVP 1 的区别

| | MVP 1 | MVP 2 |
|---|-------|-------|
| 记忆系统 | 无显式记忆 | STM/LTM 双层级，内稳态耦合遗忘 |
| 世界模型 | 无 | MLP 预测环境转换 |
| "想象"能力 | 无 | 心理模拟"往左走会怎样" |
| 智识 | 反应式 | 可记住"上次这里有食物" |
| 面板 | LTC 标识 | 记忆负载条 + STM/LTM 计数 |

## 快速开始

```bash
cd Q:\All_Items\DreamProjects\Evola

# Pygame 图形窗口
python MVPs\MVP2\evola_pygame.py
```
