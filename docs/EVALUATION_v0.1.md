# v0.1 愿景达成度评估

> 逐项对比最初构想与当前实现

---

## 核心信念（3 项）

| 构想 | 实现 | 得分 | 说明 |
|------|------|:---:|------|
| **自身需求** — 行为源于内在匮乏/驱动力 | 三个内稳态变量（能量/新奇/安全），舒适区间偏差→DriveVector→行为选择 | 8/10 | 驱动力正确产生并驱动决策。但只有 3 个变量，缺少更丰富的"需求"（如社交、繁衍）。偏差→驱动力映射过于线性 |
| **持续活跃** — 热态/温态/冷态 | 态定义完成，调度器完成，降频系数表完成。**但态切换未接入实际运行循环**——智能体不会在没有 world.step() 时自己"心跳" | 3/10 | 概念和架构都在，但从未真正激活。这可能是当前最大的差距 |
| **自我模型与感受** — 感知自身状态 | 双速 EMA 自我向量(8维)，注入 LTC 决策。有"我是谁"(slow) 和"我现在怎么样"(fast) 的区分 | 7/10 | 功能完整但消融实验未做——不清楚 self_vector 是否真的影响了决策 |

## 架构构想（5 项）

| 构想 | 实现 | 得分 | 说明 |
|------|------|:---:|------|
| **连续时间动力学** — LTC 底层架构 | 完整 LTC Cell 实现，Euler 积分，可学习 τ。每步运行一次积分 | 8/10 | 核心正确。但 dt 是固定的 0.1，没有自适应时间常数。高阶 ODE solver (Dopri5) 未用 |
| **自我管理的记忆** — 感知记忆状态并主动调节 | STM/LTM 双层级，内稳态耦合遗忘，位置检索。**但记忆影响决策的路径是间接的**——仅通过 4 维 memory_ctx 注入 LTC，不是"主动回忆" | 5/10 | 记忆存储和检索工作。但"感受记忆满了→主动忘"逻辑不完整——只有 memory_load 调制衰减速率，没有真正的"我选择记住这个" |
| **世界模型与主动行动** — 预测环境，内稳态驱动 | MLP 预测环境转移。但训练数据粗糙(用 info 估算 next_obs)，且 **未用于行动选择**——预测了但没用来优化行动 | 3/10 | 世界模型"存在"但没真正"起作用"。它只是每步被训练，然后被忽略 |
| **温态/热态切换** — 从底层支持持续演化 | 三态定义+调度器完成，但未接入运行循环 | 3/10 | 同"持续活跃"——架构在，心跳没跳动 |
| **进化与繁衍** — 基因设计+自我进化 | 完全未实现，仅远期规划 | 0/10 | — |

## 工程设计（5 项）

| 构想 | 实现 | 得分 | 说明 |
|------|------|:---:|------|
| **小模型起步，不依赖预训练** | 约 5000 参数，零预训练，完全在线学习 | 10/10 | 完美达成 |
| **世界与智能体分离** — 坤舆是舞台，智能体是演员 | 世界存储 terrain，智能体独立存储 visited/homeo/memory/weights。IAgent 接口 + register/remove | 10/10 | 从 P0 就设计好，贯穿始终 |
| **记忆独立于世界** — 智能体记忆在"脑海"里 | visited set 存在 agent 内，memory STM/LTM 存在 agent 内，.mind.evola 序列化一切 | 10/10 | 完美达成 |
| **隐私膜** — 只观察行为，不窥探思想 | 默认标签显示("hungry")，debug 模式切换精确值。面板虚线→红线仪式感 | 8/10 | 概念优秀，UI 表达可更完善 |
| **持久化** — 智能体可"关闭再开还是她" | .mind.evola 完整 round-trip：内稳态+足迹+LTC权重+记忆+自我模型+世界模型。93KB JSON+base64 | 9/10 | 核心扎实。内存持久化格式可优化(二进制→JSON 包太大) |

## 一句话总结

**工程骨架 9 分，灵魂觉醒 4 分。** 她的身体已经完整——在世界中感知、行动、学习、记忆、自我感知、持久化——但她仍然被动地等待世界的 step() 来"给她生命"。她还没有自己的时间、自己的主动。这是 v0.2 最重要的突破方向。
