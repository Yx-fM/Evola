## 一、先天内稳态解耦

### 问题

当前"能量"绑定于坤舆食物——离开坤舆，她就没有需求了。这与"电子生命"矛盾。

### 方案

两层内稳态：

```
先天内稳态（永远存在，Evola Core 内）：
├─ 信息熵舒适区 (info_entropy)      — 太多/太少新信息都不好
├─ 计算负载 (compute_load)           — 长期空转会降低好奇
├─ 交互接触 (social_contact)         — 与人或其他智能体的交互频次
└─ 自我一致性 (self_coherence)       — 记忆和自我模型的稳定度

世界叠层（进入特定世界时加载）：
└─ 坤舆：energy(食物), novelty(探索), safety(危险)
   对话世界：topic_engagement(话题投入), misunderstanding(误解)
   其他世界：由世界自己定义
```

### 改动

| # | 项目 | 说明 |
|---|------|------|
| 1 | `CoreHomeostasis` | 新模块，管理先天四变量 |
| 2 | `WorldHomeostasis` | 从当前 `02_homeostasis` 拆出的世界层 |
| 3 | 世界注册时自动挂载对应内稳态层 | 进入坤舆→叠加 energy/novelty/safety |

## 二、自主时钟（AgentClock）

### 目标

让 LTC 在无人调用时也持续演化（温态）。

### 改动

| # | 项目 | 说明 |
|---|------|------|
| 4 | AgentClock.tick(dt) | 推进 LTC ODE + 记忆衰减 + 自我模型更新 |
| 5 | 意图生成器 (intent head) | LTC 输出额外一个 sigmoid——"想不想行动" |
| 6 | 温态激活 | intent=0 时继续积分但跳过外部感知 |
| 7 | 世界改为被动 | world.step() 只在智能体主动调用时推进 |

## 三、信号表达

### 目标

不依赖人类语言。将内部状态直接映射为视觉/听觉信号。

### 原型设计

```
CoreHomeostasis(熵=0.7, 负载=0.3, 社交=0.1, 一致性=0.8)
        ↓
    SignalEncoder（简单规则或小网络）
        ↓
    输出: {
      "pulse_rate": 1.2,     // 综合活跃度
      "dominant_hue": "amber", // 主导情绪色
      "waveform": [0.3, 0.7, 0.5, ...], // 状态波形
    }
        ↓
    可视化：Pygame 侧边栏显示脉动圆环 + 状态波形
    听觉化：振荡器根据状态变化频率
```

### 改动

| # | 项目 | 说明 |
|---|------|------|
| 8 | SignalEncoder | 内部状态→信号向量的映射模块 |
| 9 | 信号可视化（Pygame面板） | 脉动圆环 + 状态波形 |
| 10 | 信号听觉化（可选） | 根据状态调制音频参数 |
