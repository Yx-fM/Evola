# 06_hot_warm_cold - 温态/热态切换

---

## 步骤 1：边界定义

> 定义热/温/冷三态的概念和降频系数，由 12_mode_scheduler 调度。  
> 06 只定义"是什么"，12 负责"什么时候"。  
> 不考虑：硬件级功耗管理、分布式部署、断点续跑（冷态恢复）

**最小成功标准**：三态的概念定义清晰，03 的文件中有一个三态的行为特征表，12 可以据此调度。

## 步骤 2：假设识别

| # | 假设 | 风险 |
|---|------|------|
| H1 | 三态（热/温/冷）的分类粒度适合当前系统，不需要更细的态（如"半温态"） | 低 |
| H2 | 各模块在各态下的降频行为可以被精确描述 | 中 |
| H3 | 智能体在温态下"后台运行"真的能产生有价值的行为（如记忆整理），而非空转 | **高** |
| H4 | 冷态就是完全暂停，与"退出程序"等价，不需要复杂逻辑 | 低 |

---

## 步骤 3：快速否决 —— H3

- **风险**：温态定义为"无外部任务时后台运行"——但在 2D 网格中，没有"外部任务"和"无任务"之分。智能体一直在环境中。温态可能没有实际意义
- **验证**：在 P0 的简单环境中，温态确实无意义——因为智能体需要持续行动。但 P1 引入 LTC 后——
  - 热态：接受观察→产生行动→更新学习。全频。
  - 温态：不行动（停在原地），但内部 ODE 继续积分，记忆整理，世界模型做想象 rollout。半频。
  - 冷态：退出程序。
- **结论**：**H3 在 P0 无效，P1 后成立**。06 先定义好概念，P0 阶段只用 HOT，12 的调度能力在 P1 后才激活。

**所以 06 的定位是"规范定义者"，不直接运行代码。**

## 步骤 4：技术选型

| 类别 | 选型 | 说明 |
|------|------|------|
| 拿来用 | **Python `enum.Enum`** | 态枚举定义 |
| 拿来用 | **Python `dataclass`** | 降频系数表结构化 |
| 改装 | **计算神经科学的"唤醒水平"模型** | 大脑的唤醒水平（从深度睡眠到高度警觉）是连续谱。改装：离散化为三态，用阈值切换 |
| 自研 | **降频系数矩阵** | 核心设计：每态下每个模块的"计算频率倍数" |

**态定义（06 产出，给 12 消费）：**

```python
class AgentMode(enum.Enum):
    HOT  = "hot"   # 全部模块满频：01感知→行动→学习 每 step 一次
    WARM = "warm"  # 降频：LTC 不行动但内部积分，记忆整理，世界模型离线训练
    COLD = "cold"  # 暂停：仅保留内存状态，可序列化到磁盘

@dataclass
class FreqConfig:
    """每个模块在每态下的运行频率倍数 (1.0 = 每 step 运行)"""
    perception:       float  # 感知（不可降频！危险检测）
    ltc_forward:      float  # LTC 前向推理
    ltc_learning:     float  # LTC 在线学习
    memory_consolidation: float  # 记忆整理
    world_model_train:    float  # 世界模型离线训练
    self_model_update:    float  # 自我模型更新

FREQ_TABLE = {
    AgentMode.HOT:  FreqConfig(1.0, 1.0, 1.0, 0.5, 0.5, 1.0),
    AgentMode.WARM: FreqConfig(1.0, 0.3, 0.0, 1.0, 1.0, 0.3),
    AgentMode.COLD: FreqConfig(0,    0,   0,   0,   0,   0),
}
# 注意：perception 在 WARM 态仍为 1.0（必须检测危险）
```

**行为特征对比：**

| 特征 | HOT | WARM | COLD |
|------|-----|------|------|
| 行动 | 每 step 行动 | 多数 step 不动 | 不行动 |
| LTC 内部 | 全频积分 | 降频积分（维持连续性） | 不积分 |
| 学习 | 在线更新 | 暂停 | 不学 |
| 记忆 | 写入 | 整理/重放 | 不操作 |
| 世界模型 | 预测 | 离线训练 | 不训练 |
| 感知 | 全频 | 全频（不可降） | 关闭 |

## 步骤 5：定向查文献

1. **Arousal & Performance (Yerkes-Dodson Law, 1908)**：心理学经典——唤醒水平与表现呈倒 U 型。太高（恐慌）或太低（昏睡）都不利。我们的 HOT↔WARM 映射到"高唤醒↔低唤醒"，但优化目标是内稳态而非外部任务表现。
2. **Default Mode Network (DMN)**：人脑在静息状态（不做任务）时活跃的网络——负责自传体记忆、未来规划、自我反思。映射到 WARM 态的"记忆整理 + 世界模型离线训练"。这是 WARM 态最有价值的参照模型。
3. **Resource-Aware ML**：边缘设备上的"自适应推理"（如 anytime neural networks）在不同资源条件下使用不同的计算预算。我们的降频系数表就是最小化的"资源感知"版本。
