# 02_homeostasis - 内稳态与本能模块

---

## 步骤 1：边界定义

> 输入：感知事实 `Facts{food_dir, is_new_tile, danger_near, energy_change}`  
> 输出：驱动力向量 `DriveVector{energy, novelty, safety}`  
> 不考虑：多智能体社会驱动力、情感模型（快乐/悲伤/沮丧）、激素调节

**最小成功标准**：三个内稳态变量独立运行，偏差正确计算，驱动力合成后能指导动作选择（由 10_sensorimotor 消费）。

---

## 步骤 2：假设识别

| # | 假设 | 风险 |
|---|------|------|
| H1 | 内稳态偏差可以完全取代"外部奖励函数"驱动行为 | 低 |
| H2 | 三个基本变量（能量 / 新奇度 / 安全）足以产生类似低等生物的本能行为 | 低 |
| H3 | 驱动力向量的**线性加权**能有效指导行动选择 | **高** |
| H4 | 人工定义的舒适区间能泛化到不同世界配置 | 中 |
| H5 | "新奇度"可以用"访问频次"做近似，不需要复杂的信息熵计算 | 中 |

---

## 步骤 3：快速否决 —— H3

- **风险**：`energy_drive=0.8` + `novelty_drive=0.7`，线性 softmax 概率约各 50%，智能体在"去食物"和"去新区"之间反复横跳，两者都完不成
- **验证**：纸上推演——两个驱动力都高时，不加门控的行为是振荡的。决策需要的是"决定"而非"加权平均"
- **结论**：**H3 被否决**。驱动力的合成应由 10_sensorimotor 的**优先级门控**处理（安全 > 能量 < 0.3 > 探索 > 随机），而非在 homeostasis 内部线性求和。homeostasis 只负责输出原始驱动力，不做融合

---

## 步骤 4：技术选型

| 类别 | 选型 | 说明 |
|------|------|------|
| 拿来用 | **Python `dataclass`** | 结构化 Facts / DriveVector，类型安全，无额外依赖 |
| 拿来用 | **NumPy** | `np.clip` 将偏差限制在 [0, 1]，`np.interp` 做舒适区间的线性映射 |
| 改装 | **Lorenz-Tinbergen 驱动力模型** | 行为生态学的经典模型：每个驱动力有"蓄水池"（随时间累积）和"泄水阀"（行为缓解）。改装：用纯数学函数代替生物阈值 |
| 改装 | **Set-Point Theory** | 生理学中的"设定点理论"——身体维持某个变量的目标值。改装：不做负反馈环路（那是内分泌系统的事），只做偏差计算 |
| 自研 | **舒适区间 + 偏差计算** | 核心创新：不追求"最小化 error"（那是 RL），而是"回到舒适区"。舒适区是一个区间而非点——只有偏离区间才产生驱动力 |

**各变量的具体实现方案：**

```python
# 能量：线性递减 + 进食恢复
energy[t+1] = clip(energy[t] - ENERGY_DECAY*dt + intake, 0, 1)

# 新奇度：访问频次归一化
visit_freq[pos] += 1
novelty = 1.0 - min(visit_freq[pos] / MAX_VISITS, 1.0)

# 安全：危险源距离反比
safety_drive = clip(1.0 / (min_danger_dist + 1e-6), 0, 1)
```

**舒适区间设计原则：**
- energy 舒适区 [0.5, 1.0]——低于 0.5 开始产生觅食驱动力
- novelty 舒适区 [0.3, 0.8]——太低（无聊）或太高（混乱）都产生驱动力
- safety 舒适区 [0, 0.2]——安全驱动力只在高危时产生，low baseline

## 步骤 5：定向查文献

1. **Lorenz-Tinbergen "Psychohydraulic Model" (1950s)**：经典行为生态学理论，驱动力如同蓄水池，水满了就产生行为——这是我们"偏差累积"概念的直接来源。注意：该模型已被现代神经科学修正（不存在独立"蓄水池"），但作为工程隐喻完全有效。
2. **Set-Point Theory (Keesey & Powley, 1986)**：生理学中身体维持体重/体温目标值的理论。应用到 AI：每个内稳态变量有"理想区间"，偏差 = 距离区间的远近。比直接最小化误差更鲁棒（不要求精确值）。
3. **Free Energy Principle (Friston, 2006-)**：主动推理框架的核心——所有行为都旨在最小化"自由能"（预测误差 + 不确定性）。我们的内稳态偏差 ≈ 自由能简化版。渐进：P2 的 05_world_model 可以引入更完整的 FEP 实现。
4. **Curiosity-driven RL (Pathak et al., 2017 "ICM")**：内在好奇心模块用"预测自身行为的后果"来做探索奖励。我们的 novelty 驱动更简单（靠访问频次），但 P2 可与 ICM 结合升级。
