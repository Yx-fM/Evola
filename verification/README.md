## 二、优先级定义

| 级别 | 含义 | 说明 |
|------|------|------|
| **P0** | 基础设施 / 最高优先 | 无此无法启动后续工作；独立可建；快赢 |
| **P1** | 核心智能架构 | 依赖 P0 就绪；决定未晞的智能本质 |
| **P2** | 高级认知能力 | 依赖 P1 就绪；提升智能水平 |
| **P3** | 集成验证 / 远期探索 | 依赖 P0-P2 就绪；最终集成或远期研究 |

## 五、P0 需求详情（当前阶段）

### P0-1: 08_kunyu —— 坤舆世界

**目标**：构建一个因果连贯的、AI可探索的 2D 网格世界。

**前置准备**：见 [08_kunyu/README.md](08_kunyu/README.md)（后续补充完整五步法）

**需求**：
1. 2D 网格地图（可配置尺寸）
2. 实体系统：智能体、食物、墙壁、危险源
3. 物理规则：碰撞、视野范围限制
4. 时间步进，预留 `dt` 参数（对接连续时间模型）
5. 完整的观察-行动-反馈闭环

**验收标准**：
- [ ] 智能体能感知周围 5×5 范围内的实体
- [ ] 智能体能执行移动、吃、等待等基本动作
- [ ] 食物周期性再生，墙壁阻挡移动
- [ ] 世界状态可被序列化/反序列化
- [ ] 键盘操控可验证世界运转
- [ ] `step()` 接口预留 `dt` 参数

**输出物**：
- 坤舆世界引擎代码
- 测试用例（世界规则验证）
- API 文档

**接口**：
- `step(action, dt=1.0) → (observation, reward)`
- `render()` → 可视化
- `get_state() → dict`

---

### P0-2: 02_homeostasis —— 内稳态本能模块

**目标**：构建先天预设的本能模块，内部偏差转化为行为驱动力。

**前置准备**：见 [02_homeostasis/README.md](02_homeostasis/README.md)（后续补充完整五步法）

**需求**：
1. 内稳态变量：能量、新奇度、安全
2. 舒适区间 + 偏差计算
3. 驱动力向量合成
4. 本能随时间累积
5. 行动反馈更新内稳态

**验收标准**：
- [ ] 能量变量从 1.0 递减到 0，吃到食物后恢复
- [ ] 驱动力向量可指导行动选择
- [ ] 独立纯逻辑验证通过
- [ ] 与 08+10 对接后表现出"饿了去找吃的"

**接口**：
- `update(facts: Facts) → None`
- `get_drive() → DriveVector`
- `get_state() → dict`

---

### P0-3: 09_junjian —— 钧鉴观察工具

**目标**：只记录行为轨迹、不侵入内部思考。

**前置准备**：见 [09_junjian/README.md](09_junjian/README.md)（后续补充完整五步法）

**需求**：
1. 行为轨迹记录（时间、动作、位置、触发原因）
2. 内稳态标签（"饿"/"好奇"，非原始数值）
3. 因果链路可视化
4. JSON/CSV 导出

**验收标准**：
- [ ] 记录完整实验的行为轨迹
- [ ] 回放可逐帧重现
- [ ] 导出的数据可被 matplotlib 可视化
- [ ] 不暴露内部向量原始值（保留开发者开关）

**接口**：
- `log_action(agent_id, action, cause_label, world_state)`
- `log_homeostasis(agent_id, state_labels)`
- `export(file_path)`

---

### P0-4: 10_sensorimotor —— 感知-行动桥接层

**目标**：将原始网格翻译成事实，将驱动力翻译成动作。

**前置准备**：✅ 已完成，见 [10_sensorimotor/README.md](10_sensorimotor/README.md)

**边界定义**：
- 输入 5×5 网格 或 驱动力向量
- 输出结构化事实 或 离散动作
- 不考虑 NN 感知（P1 做）

**关键结论**：
- H3 部分否决：线性加权导致振荡 → 引入 **优先级门控掩码**
- 技术选型：纯 Python 规则系统
- 参考：Subsumption Architecture (Brooks, 1986) 分层行为控制

**验收标准**：
- [ ] 5×5 网格正确解析为 food_dir / is_new / danger
- [ ] 优先级门控：安全 > 能量 < 0.3 > 探索
- [ ] 动作选择在门控下不振荡
- [ ] 与 08 + 02 联调通过

**输出物**：
- `impl/perception.py`
- `impl/action_selection.py`（含门控）
- `test/test_sensorimotor.py`

## 九、当前里程碑

### 第一里程碑：P0 全部就绪

**目标**：一个能用本能驱动简单行为的智能体，在一个可观察的 2D 世界中存活。

**P0 包含**：08_kunyu + 02_homeostasis + 09_junjian + 10_sensorimotor（4 个模块）

**具体场景**：
1. 智能体出生在 2D 网格中，初始能量 1.0
2. 能量每秒递减 0.01（饥饿累积）
3. 10 感知模块解析 5×5 视野，发现附近有食物
4. 02 内稳态感知能量 < 0.5，驱动"觅食"
5. 10 行动模块使用门控优先级选择"向食物移动"
6. 智能体移动到食物，吃掉，能量恢复
7. 09 钧鉴记录完整行为轨迹
8. 人类可通过钧鉴回顾实验过程

**状态**：🔴 未开始

**启动顺序建议**：
1. 08_kunyu（先搭舞台）
2. 10_sensorimotor（搭桥）
