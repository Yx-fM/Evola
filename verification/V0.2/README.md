## 新增模块

| 模块 | 说明 |
|------|------|
| `13_core_homeostasis` | 先天内稳态——信息熵、计算负载、社交接触、自我一致性 |
| `14_agent_clock` | 自己的时间步进器——tick(dt) 推进 LTC + 记忆 + 自我模型 |
| `15_signal_encoder` | 内部状态→视觉/听觉信号映射 |
